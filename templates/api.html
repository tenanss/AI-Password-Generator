DOCUMENTAZIONE API

Password per i tuoi script e strumenti.

Un solo endpoint, GET /api/v1/generate, con la stessa logica del generatore nel browser: casualità crittografica, nessun carattere favorito, almeno un carattere per ogni tipo scelto.

Dove nasce la password

Le password richieste tramite API vengono generate sul server, perché è lì che l'API vive. Non vengono salvate né registrate, e ogni risposta porta l'header Cache-Control: no-store, così non finiscono in nessuna cache.

Per la massima riservatezza usa il generatore nel browser: lì la password non lascia mai il tuo dispositivo.

Richiesta

GET /api/v1/generate

Tutti i parametri sono facoltativi e vanno nella query string. I valori booleani accettano true o false.

ParametroTipoPredefinitoDescrizione
lengthintero, 8–12816Numero di caratteri della password.
lowerbooleanotrueMinuscole a–z.
upperbooleanotrueMaiuscole A–Z.
digitsbooleanotrueNumeri 0–9.
symbolsbooleanotrueSimboli !@#$%^&*()-_=+[]{};:,.<>?/~.
exclude_ambiguousbooleanofalseEsclude i caratteri che si confondono: 0 O o 1 l I.

Esempio

Richiesta
$ curl -s "https://ai-password-generator-twpu.onrender.com/api/v1/generate?length=24&symbols=false"
Risposta · 200 OK
{
  "password": "15Ftg4w6TfRetmE7dl4FtoWm",
  "length": 24,
  "entropy_bits": 142.9,
  "strength": "very_strong"
}
CampoSignificato
passwordLa password generata.
lengthLa lunghezza richiesta.
entropy_bitsBit di entropia: lunghezza × log₂(caratteri possibili), arrotondati a un decimale.
strengthLivello di robustezza, vedi sotto.

Livelli di robustezza

Valore di strengthEntropiaSulla pagina

strongda 70 a meno di 100 bitForte
very_strong100 bit o piùMolto forte

Errori

Una richiesta non valida riceve la risposta 422 Unprocessable Content, con il motivo nel campo detail. Succede in due casi:

  • length fuori dai limiti: meno di 8 o più di 128 caratteri.
  • Nessun tipo di carattere attivo: lower, upper, digits e symbols tutti a false.

Passphrase

GET /api/v1/passphrase

Genera una passphrase di parole italiane, pensata per le password da ricordare e digitare a mano: computer, gestore di password, Wi-Fi. Le parole vengono estratte a caso da una lista di 2.048 parole, con la stessa garanzia crittografica delle password. Come per /api/v1/generate, la passphrase nasce sul server, non viene salvata né registrata e la risposta porta Cache-Control: no-store.

ParametroTipoPredefinitoDescrizione
wordsintero, 4–107Numero di parole.
capitalizebooleanotruePrima lettera della prima parola maiuscola.
numberbooleanotrueUna cifra casuale in fondo all'ultima parola.
separator- . _ space-Carattere tra le parole; space indica lo spazio.
Richiesta
$ curl -s "https://ai-password-generator-twpu.onrender.com/api/v1/passphrase"
Risposta · 200 OK
{
  "passphrase": "Sfacelo-uragano-grattare-oscurare-puntare-dozzina-monile7",
  "words": 7,
  "entropy_bits": 80.3,
  "strength": "strong"
}

Entropia: parole × 11 bit (log₂ di 2.048), più 3,3 bit per la cifra finale. Maiuscola e posizione della cifra sono fisse, quindi non aggiungono bit: servono a rispettare le regole sulle password dei computer aziendali. Il calcolo vale anche se un attaccante conosce la lista, perché le parole le sceglie il computer a caso. I livelli di strength sono gli stessi delle password.

Errori 422: words fuori da 4–10, oppure separator diverso dai quattro valori ammessi.

Lista di parole: BIP-39 italiano, licenza MIT.
